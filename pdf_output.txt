Reverse Engineering from Code using Agentic AI
1. Project Overview
Software companies often have large and old software projects whose original documentation, design
diagrams, and detailed explanations are missing or outdated. Understanding such software requires
developers to manually read thousands of lines of code and identify how different files, functions, classes,
and modules are connected.
The proposed project, ΓÇ£Reverse Engineering from Code using Agentic AI,ΓÇ¥ aims to develop an AI-based
system that automatically analyzes an existing software codebase and converts it into an understandable
representation of the software.
The system will accept a source-code project such as a ZIP file or repository and automatically identify the
structure, dependencies, function relationships, data flow, control flow, and important modules. Using 
Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), program analysis, and
LangGraph-based multi-agent orchestration, the system will generate human-readable explanations and
reverse-engineering artifacts.
The main goal is to help developers understand an unfamiliar or legacy software system without manually
studying the entire codebase.
2. Problem Statement
When developers receive an existing or legacy software project, they may not know:
What the software actually does.
Which files belong to which module.
Which functions call other functions.
How data moves through the system.
Which components depend on each other .
How different modules interact.
What the purpose of an individual function or class is.
What the overall architecture of the software looks like.
Traditional reverse-engineering tools can extract structural information, but the information may still be
difficult for a developer to understand. On the other hand, an LLM alone may generate incorrect
explanations because it does not always have complete knowledge of the relationships within a large
codebase.

10. Research Contribution
Existing research has explored individual tasks such as:
Code summarization
Program slicing
Decompilation
UML generation
Code understanding
Requirements-to-code traceability
However , these tasks are generally addressed separately.
The proposed project aims to combine multiple reverse-engineering capabilities into a single agentic
framework.
Another important contribution is the use of a verification-driven architecture. Since LLMs can generate
incorrect or unsupported explanations, the proposed system will use program-analysis evidence and a
verification agent to check AI-generated results against the source code.
Thus, the project combines:
Traditional Program Analysis + RAG + LLM + LangGraph Multi-Agent System + Verification
to create a more reliable reverse-engineering platform.

comprehension, documentation, and reverse engineering.
